What we built

One assistant, two channels, a new platform underneath.

Searching for a flight meant filters, open tabs and manual comparisons. Vola wanted travellers to ask for a trip the way they ask a friend, in the chat where they already plan it.

WhatsApp · Twilio

GoVola AI in WhatsApp

Travellers write "something warm in August, flying from Cluj" and get flight options with live prices in the chat. Added to a group, the assistant posts the options as a poll and the group books together. No app, no account, free to use.

Web

AI mode on vola.ro

The same assistant on the website: voice search, AI Deal Finder and Agent mode, next to classic flight and hotel search.

Frontend

A rebuilt vola.ro frontend

We rebuilt the customer facing frontend of vola.ro, from search through results to the AI mode screens.

Backend

A rebuilt backend

We rebuilt the services behind search and booking that both the website and the WhatsApp assistant call.

How we tested it

A chatbot that sells tickets gets tested like a checkout.

Agents plus engineers. Agents write and run the tests, engineers verify every one of them.

Full conversations

From the first message to the booking link, in one to one chats and in group chats with polls.

On every change

Suites run from every pull request, every branch and on a schedule against production.

Self healing

When the vola.ro interface changes, the affected tests are repaired and an engineer checks them again.
